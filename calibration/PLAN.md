# DMD—双 SLM—相机标定方案

## 1. 目标与当前光路

目标：用户在开发环境生成标定相位包，连接设备后由软件通过相机反馈估计/补偿可观测的方向、偏移和输入区域关系，保存可复查结果。打包版只导入相位包并执行采集与搜索，不依赖 PyTorch；开发环境也支持测量后现场训练。

已确认：

- 当前使用普通显示器输出 DMD，暂不使用 F4321。
- DMD → SLM1 为等焦距的 4f 成像中继，理想倍率 `M = -f2/f1 = -1`。
- 因此该段保持物理尺寸，理想倒像相当于旋转 180°；额外反射和硬件安装方向以实测为准。
- DMD、SLM1、SLM2 的完整面板通常为 1920 × 1080；640、432、768 等是有效输入区域。

仍需按实物核实：波长、SLM1 → SLM2 → 相机的距离和有无额外透镜、像素间距、器件 LUT、偏振、相机型号/输出格式。现有模型默认 532 nm、200 mm、100 mm。实现的初始传播模型假设后两段自由空间，不把默认值当成实测值。

## 2. 必须区分的概念

### 2.1 均匀相位参考与撤去器件

SLM 全屏同一灰度提供均匀驱动参考，不会自动消除器件像差、偏振失配和照明不均匀。本实现统一灰度 0，并在 LUT 中把其相位作为全局参考；整个面板外围也为灰度 0，避免仅有效区与背景存在人为相位台阶。

### 2.2 强度目标与相位图

点阵、箭头、E、带缺口边框是希望在相机得到的强度分布。必须用物理传播模型求相位；将这些图直接当作 SLM 灰度输入不等价。

现有 demo 棋盘格只是演示播放/预览。`processing/generate_alignment_patterns.py` 是保留的旧图案工具，不被真实自动标定调用。

### 2.3 相位屏位置与输出光斑位置

相位图在面板上平移，可能使相机图案平移、变形，也可能几乎不变。纯线性相位斜坡平移可能主要改变全局相位，不能据此唯一确定相位屏偏移。

因此以固定非对称相位图的相机匹配分数搜索控制参数；另测局部响应矩阵作为诊断，不强行把不可逆矩阵反求成“正确偏移”。需要区分通过相位斜坡改变出射方向和移动实际相位屏位置。

### 2.4 4f 成像与末端相机观察

只确认了 DMD → SLM1 的成像关系。两片 SLM 为均匀相位时，后续传播仍可能产生衍射。末端若无法稳定定位单点，流程停止并保存原因，不硬套几何模型。可在后续增加辅助成像/共轭平面观察、相位辅助成像或完整传播参数拟合。

## 3. 坐标与尺度

- 相机原始像素：X 向右、Y 向下；界面预览方向不参与计算。
- 控制偏移：以实际器件面板像素为单位，相对面板居中位置。
- 图像方向：先水平/垂直翻转，再顺时针旋转，与现有硬件发送保持一致。
- 数值传播：SLM1、SLM2 使用独立网格及采样间距；DMD → SLM1 引入等倍率倒像，后两段复用 ASM。第一段传播后按坐标重采样复光场再进入第二层。
- 配置分别记录器件物理像素间距、各层 ASM 数值采样和数组大小、相位优化控制点与硬件导出尺寸。

举例：640 × 5.4 μm = 3.456 mm。在当前 1:1 中继下，对应 SLM1 432 × 8 μm 和 SLM2 768 × 4.5 μm。输入尺寸改变则重新计算有效区，不将所有图像缩放为 640。

上述 432/768 是设计口径对应的硬件有效区，不是 ASM 网格大小，也不保证自由传播后的光束恰好充满 SLM2 有效区。主项目 ASM 数组目前均为 640 × 640，经验数值采样分别为 13 μm / 6.4 μm。本标定采用这两个采样默认值，另外用 512/1024 的计算边长提供 6.656/6.5536 mm 视野；每层都可分别设置。完整参数表和旧配置迁移方法见 [README.md](README.md#网格与质量参数)。

开发界面会在口径、采样或网格变化后自动扩大不足的网格：先补足 SLM2，再让 SLM1 覆盖 SLM2。足够大的手动值保持原值，自动扩展以 64 为步长，上限 4096；调整结果写入训练配置。导入的相位包保留训练坐标，不自动扩展。相位优化控制点可分别设为 640 × 640，训练时仍会重采样到各片 SLM 的原生有效区。

相机若确认为 4 μm、无 binning/缩放，可用相机像素距离换算传感器平面的物理长度。DMD 到相机的对应关系不等于任意三维空间长度，也不能替代相机内参/透镜畸变的完整标定。

## 4. 阶段 A：准备与采集

1. 验证设备启用、连接、面板尺寸、输入口径、SDK 路径，以及导入标定包的完整性和训练参数。仅开发训练模式检查 PyTorch 与模型依赖。
2. 未连接时生成全黑 DMD 参考与 SLM 均匀参考用于连接，不使用用户实验相位或 demo 棋盘格。
3. 停止播放、录像和同步保存；固定曝光/增益并确认 SDK 返回。
4. 使用完整的 8 位相机帧。保持白平衡、gamma 等处理固定。
5. 每次发图后等待稳定，跳过旧读取、丢弃若干新帧，再取不同帧号的多帧平均。
6. 原始帧、帧号、曝光、设备信息、发送图案及控制参数逐批保存。

这属于软件协调采集。对于内部缓冲、慢 SLM 响应、长曝光，应实测等待时间。以后可接硬件触发/设备帧确认，但不能将当前方式描述为硬同步。

## 5. 阶段 B：DMD 几何与方向

两片 SLM 均匀相位，DMD 依次显示黑图和中心到外围的已知单点。单点身份由采集顺序确定，即使相机只看到部分区域，也不会混淆周期棋盘格的格点编号。

处理步骤：

1. 扣除背景，检出信噪比足够且未被边界裁切的点。
2. 拒绝多峰歧义、异常面积和无法定位的点。
3. 至少八个分布不退化的有效点，分出独立验证点。
4. RANSAC 拟合 DMD → 原始相机的二维仿射关系；检查条件数及独立 RMS 误差。
5. 分解方向/镜像，应用 DMD 补偿，再重新采点验证方向确实改变。
6. 保存原始映射、补偿后映射、误差、无效点原因和传感器平面尺度。

当前旋转/翻转无法纠正强剪切/透视，因此补偿后的轴关系仍明显异常时停止。未来若需要可以增加单应性/畸变模型，但要有独立验证点，不能为追求低拟合误差无限增加自由度。

目标默认定位在相机中心；其对应训练网格位置由实测映射计算。若超出计算视野或实际口径，提示粗调光路/扩大计算区域，不伪造完整覆盖。

## 6. 阶段 C：ASM＋SGD 生成标定相位

### 训练组合

| 组合 | DMD | SLM1 | SLM2 | 目标位置 |
|---|---|---|---|---|
| SLM1 单独 | 指定白色口径 | 优化 | 均匀参考 | 最终相机平面 |
| SLM2 单独 | 指定白色口径 | 均匀参考 | 优化 | 最终相机平面 |
| 双 SLM 联合 | 指定白色口径 | 联合优化 | 联合优化 | 最终相机平面 |

每个组合生成非对称三点、箭头、不对称四点、独立五点。前三者的用途可分配为拟合与检查，`holdout` 不参与硬件参数搜索。相位训练必须学习 holdout 对应输出，所谓独立指它未参与实物参数拟合。

DMD 方向补偿会改变白色区域形状；训练使用已测出的 DMD 指令方向，不能先按未旋转口径训练，最后才旋转 DMD。SLM2 单独训练的入射场包含前一段的传播，不默认是平面波。

### 参数化和导出

1. 两片 SLM 分别在较低维相位网格优化参数，双线性插值到各自器件有效像素。
2. 各器件的原生像素按物理间距映射到自己的 ASM 网格，相位之外为均匀参考。SLM1 传播后按坐标插值复光场实部/虚部至 SLM2 网格，向更粗采样转换时先作抗混叠低通。相机强度和目标使用最终 SLM2 网格。
3. 使用强度归一化后的振幅误差和低通量惩罚，`torch.optim.SGD` 更新相位。
4. 按 LUT 选择圆周相位最接近的 8 位灰度，保存 PNG 与 rad 数组。
5. 用**量化后实际灰度对应相位**重新传播，保存预测强度并检查目标匹配。

### 开发训练与设备端导入

开发环境把上述十二组相位、量化后预测强度、目标、训练参数和 LUT 数组写成一个标定目录，`manifest.json` 记录阶段、网格、分数和文件校验值。设备端读取这些数据即可搜索和验证，无需重新执行 ASM 或载入 PyTorch 模型。

导入后锁定训练参数，保留采集和搜索参数可调；检查文件完整性、原生相位尺寸、参考数组形状和三种组合的独立目标。纯 PNG 相位图可正常播放，但不足以直接用于自动标定，因为缺少对应的预测参考和坐标定义。

测量 DMD 几何后始终保存 `training_request.json`，其中包含实际方向及使目标落在相机中心的参数。导入模式保持包内的预测位置不变，并检查实际白色照明口径是否与训练一致（容许数值掩模差异不超过 0.5%）、目标是否满足覆盖率。通过即可继续；不通过则恢复原设置，提示在开发环境使用实测参数重新训练再导入。此时不会在设备端临时改变传播模型或把预测图移动到亮斑位置。

数值采样必须做收敛检查。层间复光场插值是近似，不是严格的缩放角谱算法；SLM1 的计算视野应覆盖 SLM2 网格。粗网格不能解析所有原生像素细节；零填充有限计算域也不能代替真实全空间。经验采样参数需要实物验证，不能仅因训练损失低就确认模型正确。相位 LUT 校准、波前测量与像素串扰建模是独立的后续工作。

## 7. 阶段 D：分别搜索 SLM 对齐参数

训练结束后固定所有相位图，不在每个错位候选处重新训练。

1. 固定另一片 SLM 为均匀参考。
2. 用点阵和箭头共同评价，初始参数取当前 UI 设置。
3. 搜索全角度粗候选和镜像，再逐级减小角度/偏移步长。
4. X/Y 偏移限制在给定半径；每次发送前验证完整图案能放进面板。
5. 与固定的相机参考预测比较，不能每个候选重新配准或平移目标掩盖误差。
6. 拟合区域包含目标与周边背景，检查有效覆盖和过曝。
7. 选出较好的控制参数，分别用 ±X、±Y 探测其局部相机响应。

局部关系可写作 `Δp_camera ≈ J Δq_panel`。实现使用正负位移图的相位相关估计，记录相关响应和矩阵条件数。低置信度、形变显著或近奇异时标记不可解释为平移，不把它当作可靠物理位移标尺。当前搜索本身不依赖矩阵求逆。

偏移/相位/传播误差可能具有等效性，单个末端强度相机不能保证唯一辨识全部物理自由度。结果含可验证的控制参数和限定的适用范围，不声称找到了唯一机械位置。

## 8. 阶段 E：独立和联合验收

- SLM1、SLM2 分别用未参与实物搜索的角点和五点图验证；每张都必须通过。
- 加载联合训练得到的配对相位，验证联合输出。
- 在同一联合目标上分别把 SLM1 或 SLM2 变成均匀参考，验证正确配对的输出显著优于反对照。
- 若单独通过而联合不通过，则本轮整体失败，不将局部结果当成最终标定。
- 成功后验证原实验输入在新参数下仍不越过面板，再应用到主界面并保存配置；失败/取消恢复原设置。

“1 → 2 → 3”可以作为展示目标，但不表示末端相机能直接测到中间平面的“2”。目前所有验收目标都定义在最终相机平面。若要求验证 SLM1 后的中间场，需要增加观察条件。

可继续增加：错配相位的反对照、人工小偏移/小旋转的敏感性检验、基于联合目标的第二轮微调，以及独立照明输入的泛化测试。当前实现不因未来流程尚未加入就跳过已有联合验证。

## 9. 视野不完整

- 不使用截断光斑的质心。
- 只使用明确可见、编号已知的特征点；要求有足够空间分布。
- 目标区域投影到相机后计算覆盖率，覆盖不足直接停止，不通过逐帧自由裁切“提高”分数。
- 报告未验证区域；当前结果仅适用于这次口径、波长、设备和采集设置。

较小标定图可以帮助找到光路，但不能证明整个大输入都可见。若传感器不足，完整验收需要调整光学缩放、使用更大传感器或有已知运动关系的相机拼接。移动 DMD 输入不是自动获得原场的完整拼接图。

## 10. 实施边界和后续方向

本版本已实现目录化训练、GUI 入口、真实硬件发送、原始相机采集、方向/偏移搜索、判定、报告和恢复流程。当前还没有实物验收数据。

以下情况需要后续增加模型或机械控制，当前会报告失败或不确定：

- 后两段还有透镜/4f，而训练按自由传播配置。
- 均匀相位时 DMD 点已完全衍射，不能几何定位。
- 光束没有经过所需有效区，或目标始终在传感器之外。
- 位移无可辨识强度响应、强像差、相位映射错误或偏振不匹配。
- 实际需要电动平移台/透镜/支架调整，而设备没有相应控制接口。

优先扩展次序：实机采集诊断 → LUT/波前校准 → 更精细传播模型与采样收敛 → 联合微调及更严格反对照 → 多口径/多设备标定配置 → 有电动机构时的机械闭环。
