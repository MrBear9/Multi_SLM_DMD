# 全息生成与传播模型标定

主界面第一页、第二页的「全息生成…」打开 `ui/HolographyWindow.ui`。
布局可直接用 Qt Designer 编辑；保留控件 objectName，逻辑在
`gui/holography_window.py` 和 `gui/holography_controller.py`。

点击子窗口标题栏「?」或按 F1，可打开带目录和关键词查找的
本地帮助。帮助布局为 `ui/HolographyHelp.ui`，内容为 `ui/holography_help.html`，
二者已加入 Qing.spec。帮助说明参数含义、操作顺序及几种「应用 / 载入」按钮的区别。
相机的方形像元在界面共用一个尺寸输入，手动修改会同时更新 X/Y；SDK 或旧参数
若包含不相等的 X/Y 值，会保留真实数据并提示，不静默当作方形像元。

应用几何标定后，主 UI 第三页「全息标定区域」同步显示红色目标 ROI 和橙色虚线
外围视野（沿用全息窗口倍率）。可分别隐藏、定位放大，并在实时/冻结画面和全图导航中
查看；框线使用原始坐标，随预览方向与缩放变化。手动 ROI、采集与保存的原始图像不变。
相机身份、采集几何或目标/SLM 设置失配时隐藏并提示重新核验。

## 环境和运行

在外部开发环境安装 `python -m pip install -r holography/requirements.txt`。
主程序不导入 torch。子窗口指定该环境的 `python.exe` 和本源码目录下的
`holography/worker.py`。训练使用 QProcess 独立进程；结果和进度通过 JSON 行
传递，大数组写入任务目录的 NPY 文件。PyInstaller 只包含 UI 和控制层，排除
worker、optics 和 torch；发布版如需训练，仍要配置外部 Python 和这份源码。
本实现完全位于 tools，不导入父项目 models，也没有复制第三方项目源文件。

### 三种操作

1. **全息生成（离线）**：选择目标强度图、单 SLM1 / 单 SLM2 / 双 SLM，填写
   尺寸和实际传播距离。优化灰度控制点，经原生像素插值、8 位量化后传播。
   目标图是 8 位强度目标（不做 sRGB 解码），可选择等比例留边、等比例裁剪或拉伸。
   适配使用目标平面的物理宽高比，方形数值数组不意味着方形物理视野。
   目标物理视野宽高定义输出平面的范围，不等于 SLM 面板尺寸。
   SLM1、SLM2 分别设置控制点宽、高，优化数组按各自的矩形尺寸创建。
   默认对应各片的默认有效区；「控制点匹配有效区」可一键更新所选 SLM 的
   控制点尺寸。例如有效区 1920×1080，对应同尺寸逐像素优化；也可用 960×540
   降低参数量，再插值到有效区。修改有效区不会自动覆盖手动控制点。
   旧 JSON 的 `controls` 会解释为每片原来的方形宽高，新文件保存四个独立字段。
2. **相机回环优化**：主界面先连接所选 SLM 和相机、关闭自动曝光，完成几何对准。
   默认无模型时先标定传播模型，通过独立验证才继续。每个候选都显示量化相位，
   等待稳定、丢帧、平均并重复采集，使用实拍振幅前向值和模型梯度更新相位。
   实拍改善超过门槛及测量波动才接受；否则恢复相位与 Adam 状态并缩小步长。
   导出已接受的最佳相位并复拍，复拍漂移会单独警告。可选在线模型更新，默认关闭。
   模型不准时代理梯度可能无效，允许停止并保留初始化，不强行继续变差的更新。
3. **传播模型标定**：显示不同尺度的随机灰度图案，采集灰度输入/实拍输出对。
   按不同相位分为训练、模型选择、独立验证三组，后两组各约 20% 且至少两组相位。
   学习平滑入射振幅/波前、各片 SLM 的单调 LUT 和低阶像差，以及可选的相干背景场
   与非相干底光。选择组和独立验证误差相比更新前均改善至少 2% 才设置 `validated=true`；这仅是相对改善
   检查，不等于实验验收。未通过的模型会保存诊断数据，但不能导入生成流程。

### 回环与模型设置、诊断

子窗口新增「回环与模型」页，设置预标定、在线更新、复拍次数、重试、步长衰减、
停止条件及模型验证门槛；这些参数随全息 JSON 保存。旧采集间隔自动迁移为每步采集。
模型预标定组数/轮数仍在「光路与训练」，模型路径在「文件与环境」。
更新在线模型时，候选相位只加入训练集；固定选择/验证集不用于梯度训练。
接受新模型后重置相位 Adam 动量；拒绝新模型则完整恢复原参数。
所有采集磁盘存储、按需读取，不把完整相机数据集常驻显存。

- `feedback_history.jsonl`：实拍候选、接受/回退、步长、模型版本与更新结果。
- `feedback_summary.json`：初始化/最佳复拍误差、停止原因及复拍一致性。
- `best_state.json`：最近已接受相位的路径和误差；中断也保留，PNG 可从主 UI 手动导入。
- `captures/`：样本、初始化、候选、回退、最佳复拍的相位和原始/校正图像；复拍单独存储。
- `model_updates/attempt_*/`：每次模型尝试的参数、LUT、数据分组及验证指标；失败版本也保留。
- `result.json`：最终采用的模型路径与相位结果；通过验证的模型路径自动回填子窗口。

界面分别显示实拍、最佳实拍、模型验证和模拟误差；模型/相位均采用归一化振幅均方误差，
不代表绝对光效率，也不能与旧强度代理损失直接比较。模型是当前系统的有效拟合，
不保证唯一分离各器件的物理误差。曝光/增益/光路/映射改变后仍需核验或重新标定。

无需硬件的专项回归：在仓库父目录运行
`python -m unittest tools.holography.feedback_regressions`，覆盖错误梯度回退、
Adam 状态恢复、模型留出验证/拒绝、在线版本、最终漂移、参数保存及曝光缓存。

单层模式不要求另一片 SLM 连接。单层 SLM1 使用独立的「SLM1 → 目标平面」距离，
双层使用「SLM1 → SLM2」和「SLM2 → 目标平面」。直接采集时目标平面就是传感器面；
若透镜中继采集，填写 SLM 到被成像的重建平面的传播距离，不是到相机外壳的距离。
不应把单层和双层模型混用。
任务期间，已连接的非活动 SLM 设为全屏灰度零，结束或取消后恢复原显示。
仍在光路中的非活动器件产生的误差只能由当前配置的等效模型部分描述。

## 光学与相机约定

- 首片 SLM 有效区域内初始振幅均匀，区域外为零。模型标定可拟合平滑照明，
  不能自动获知任意 DMD 图案。DMD 保持任务开始时的静态输入；请使用与有效区
  匹配的固定照明（如白色口径），不切图。本版不支持 F4321 回环，也没有将
  DMD 图案作为模型输入；改变 DMD/光源分布需重新标定和验证。
- 两片 SLM 使用独立像素间距、原生相位尺寸、相位响应和像差；共用一个物理
  计算网格，避免把不同采样的复光场当图像直接缩放。SLM2 接收 SLM1 传播场。
- ASM 用 FFT 频率坐标、传播波与矩形带限掩膜、2 倍零填充。基础网格的宽、高独立设置，
  每个方向至少覆盖活动 SLM 对应物理尺寸乘以预留倍率及目标视野，不足只增大该方向；
  数值采样间距仍共用，不能粗于活动 SLM 像素。默认 1.5 倍是计算区域的起始余量，
  具体光路仍需通过增大网格、减小采样间距检查收敛。旧配置的 grid_size 读取为等宽高网格。
  这不是数值收敛保证，需减小采样并保留物理视野进行验证。两层较大网格会
  增加显存需求，OOM 不会被报告为标定成功。
- 首版假设已对准的共轴自由空间传播；SLM 几何变换由现有主窗口加载接口执行。
  不模拟额外透镜、明显斜面传播或任意 DMD 输入。几何不符时先调整模型，不能
  依靠像差参数吸收全部系统错误。
- 相机映射使用原始帧（不受第三页显示变换/冻结影响）。未应用几何标定时，使用
  手动有效采样、翻转、旋转和中心；Y/X 采样比例来自像元及 Binning 的 Y/X 比。
  X 右、Y 下；正角度将右方向转向下方。使用相机中心按钮不代表已测量对准。
- 「成像与采集」中的名义采样 = 像元间距 × 总 Binning ÷ 成像倍率绝对值。
  直接采集使用倍率 1，中继透镜的倒像由几何矩阵测量。当前相机提供像元时读取
  SDK；ToupTek 预设为 3.76 μm，DVP 未提供像元时保留手动值，不认定为 4 μm。
  非原生分辨率的附加采样需用户核对；实际回环优先使用验证后的几何矩阵。
- 几何矩阵支持旋转、反射、平移、尺度，以及可选仿射/透视。目标 ROI 是物理矩形
  投影到原始帧的四边形，不自动修改传感器 ROI。镜头径向畸变不在当前模型内。
  「透镜参与全息传播」暂不能运行，不能用成像倍率代替傅里叶透镜传播模型。
- 必须确认固定曝光、增益、白平衡、gamma 等条件以及正确黑白电平。
  彩色帧取绿色通道；强度扣除用户指定暗电平后保持线性，不逐张自动拉伸。
  目标视野超出传感器或饱和比例超过 1% 时失败。12 位有效数据不应随容器的
  uint16 直接把饱和码值认作 65535。

## 首版可学习项

- 8×8 对数振幅插值成平滑正照明，归一化有效区平均振幅。
- 每片 SLM 的 16 段单调相位响应，允许有限相位行程变化；导出 256 行 rad 表。
  默认灰度方向由 UI 指定。本实现学习的是在当前照明下的有效响应，不承诺是
  独立测量的真实器件 LUT；没有空间变化 LUT。
- 每片有效区的离焦、两种像散、两种彗差多项式（Zernike 形式，矩形有效区上
  求值，不宣称标准圆瞳归一化系数）。固定几何、排除整体 piston/tip/tilt。
- 平滑/小幅正则约束。未加入内容相关 CNN、相干背景复场、可学习距离，避免
  第一版同时开放太多互相混淆的参数。

所有损失基于归一化强度的平方根比较，因此不识别绝对光功率/相机增益。
校准参数可能有歧义：独立目标、不同图案的实际重建改善才是后续验收依据。

## 结果与硬件生命周期

每次任务独立目录：`job.json`、`status.json`、`captures/*/{slm*.png,raw.npy,
raw.json,observed.npy,observed.png}`。模型输出 `model.json`、`model.npz` 及 LUT；
全息输出 `result.json`、`slm1/phase.png` 和/或 `slm2/phase.png`、目标和模拟图。
完整结果目录可移机，用「载入相位结果…」再「应用生成相位」导入主界面。
相位文件就是最终优化的 8 位灰度指令，不应再次做 LUT 编码。

主程序拥有设备连接，训练进程不能打开 SDK。回环期间阻止普通播放、导入、
保存、曝光调整和另一项标定抢占硬件。停止、断开或关闭时先终止训练和取帧
事务，等待当前硬件操作结束后恢复显示，再执行断开。相机连续预览保持工作。
单次厂商 SDK 显示调用仍使用既有 GUI 硬件桥，厂商阻塞会短暂影响 UI；计算与
文件采集处理已放在外部进程/采集线程，不保证消除厂商调用的阻塞时间。

导入模型校验光学签名；实物任务还检查设备参数和固定 DMD 图像摘要。改变
布局/光路/偏振/曝光后应重新验证。离线生成允许没有硬件签名，但不能据此声称
在当前设备已验证。旧的光路自动对准功能保持原入口，本子窗口是新增功能。

## 尺寸设置与单 SLM 几何标定

1. 在「目标与尺寸」选择参考来源：所选 SLM 有效区域（双层时为 SLM1）、DMD
   输入区域或自定义像素尺寸。自定义宽高以 px 输入，配合「参考像素间距」自动
   换算物理尺寸；选择「按参考尺寸 × 倍率」即可联动目标宽高。
   DMD 640 × 640、5.4 μm、倍率 1 对应 3456 × 3456 μm；500 × 500 对应
   2700 × 2700 μm。这里允许手动填写计划使用的输入尺寸，不要求连接 DMD。
   PNG 文件像素数本身不确定物理尺寸。手动目标尺寸模式保留独立宽高设置。
2. 使用单 SLM1 或 SLM2，主窗口连接该 SLM 和相机，固定曝光及照明；无需连接
   DMD/另一片 SLM。机械粗调、偏振和 SLM 相位方向仍需正确。设置真实波长、
   有效口径、传播距离和目标视野，先在「成像与采集」核对黑白电平、等待及平均帧。
3. 在「几何标定与 ROI」点击「开始几何标定」。外部进程生成量化的球面聚焦相位，
   先采集全零灰度的平相位背景，再采集 9 个局部拟合点及 5 个局部独立验证点。
   带宽允许时，另采集完整目标的 4 个角点和 4 个边中点，只验证、不参与拟合。
   两种定位图案都逐点显示，非对称模式改变拟合点布局，避免同时显示多点的匹配歧义。
   此步骤使用解析相位，不训练传播模型，也不依赖已有相机映射或目标图文件。
4. 背景差分定位拒绝过曝、边界截断、信号不足和多峰歧义。根据选择拟合相似、
   仿射或透视矩阵。每一个拟合点及独立验证点误差均需小于设定阈值，目标四角
   也必须完整落在可采集区域。失败不会自动套用映射，采集文件保留供诊断。
5. 完成后原硬件显示恢复。检查误差、采样、旋转、镜像和覆盖率，点击
   「应用映射与目标 ROI」。随后相机回环和模型标定通过该矩阵提取并校正目标区域。
   红色 ROI 及校正结果显示最近一次任务采集帧，不另外启动持续高分辨率采集。
6. 可以保存/载入 `geometry.json`，或将已应用映射随全息参数保存。改变活动 SLM、
   距离、目标视野、成像设置后会取消映射确认；开始真实任务时再次核验相机身份、
   分辨率、传感器 ROI、SLM 显示方向/偏移及曝光等配置。参数不匹配时需重新标定。
   修改手动映射值会退出实测矩阵。旧的 DMD + 双 SLM 自动对准暂不与此入口联动。

`geometry.json` 保存矩阵、原始帧尺寸、物理定位点、测得坐标、验证误差及硬件签名；
`points.json` 在每一点结束后保存，`captures/` 保存相位、原始帧和采集元数据。
聚焦相位按当前波长、距离和理想灰度相位关系生成，超过像素采样带宽时停止。
这是一份基于模型定位点的有效几何映射：拟合误差小不证明绝对物理尺度准确；
需要精确物理计量时，使用独立已知尺寸的标尺/图案核验。严重像差或错误 LUT 可能
导致光斑定位失败，应先调整光路。几何标定不能替代传播模型、LUT 或像差标定。

## 验证

从项目根目录运行：
`python -m unittest tools.holography.test_holography tools.holography.test_geometry -v`。

### 计算视野与初始化

- `grid_margin` 是计算视野预留倍率，默认 1.5，可设置 1～8。所需宽、高分别为
  `max(活动 SLM 最大物理尺寸 × 倍率, 目标物理尺寸)`；不足的网格向上取 64 的倍数。
  这是计算范围，不是成像倍率，也不是 ASM 内部宽、高各 2 倍的 FFT 补零。
- `grid_limit` 是用户设置的单轴资源上限，默认 4096，可提高到 16384；不根据显存自动决定。
  开始前超限会报告实际所需尺寸，保留原设置。界面实时显示预计网格、FFT 尺寸及一个
  complex64 FFT 数组的 MiB；它不含梯度、多个中间数组、初始化临时数组和 FFT 工作区，
  不是训练总显存估计。提高上限并不保证可运行。
- `initialization=random`：以中间灰度对应相位为中心，在 `±init_range_rad` 范围随机初始化，默认约 ±π，
  可改为 ±0.5 rad，0 为平相位。范围只控制起点，不约束训练后的相位。
  初始相位通过当前模型的 LUT 和灰度方向映射到最接近的 8 位灰度；量化存在少量误差。
  采用中间灰度为中心，避免小范围随机相位跨越 0/255 灰度端点后在粗控制点插值中引入大跳变。
- `initialization=gs`：从同样的随机起点做 GS 投影初始化，默认 `gs_iterations=30`。
  在目标物理区域约束振幅并保留区域外的场，使用带限补零 ASM 的伴随传播；双层按
  SLM2、SLM1 顺序更新，考虑入射场、已学习的像差和 LUT。控制点转换使用圆周相位插值。
  有限孔径、重采样、低分辨率控制点和 LUT 使其成为投影 GS 变体，不是传播的精确逆运算。
  用实际前向模型比较模拟误差，保留包括随机起点在内的最佳候选，然后进入原有 Adam 优化。
  `result.json.initialization` 保存初始/选择后的误差和选中迭代；这不保证硬件重建改善。
- 初始化只用于全息生成和相机回环；不替换模型标定的探测图案或几何定位相位。
  全部 Torch 计算仍在外部 worker 中，迁移时更新整个 `tools/holography` 文件夹，
  包括新增的 `initialization.py`。主 GUI 不导入 Torch。

### 目标计算尺寸

目标计算宽、高独立（16～4096），用于目标适配、传播输出采样和相机映射。
“匹配目标比例”保持计算宽度，按目标物理宽高比计算高度并取整；只在点击时调整。
界面显示两个方向的目标采样间距。物理视野和硬件相位尺寸保持原设置。
旧配置及模型签名中的 `output_size` 按等宽高读取。

### 几何标定诊断文件

#### 紧凑光斑与有限饱和（定位器版本 2）

几何标定使用去除宽缓背景后的紧凑峰值寻找候选，随后对原始背景差分拟合
椭圆高斯光斑与平面背景。候选需要通过尺寸、形状、外围覆盖和拟合残差检查，
不能再仅凭整片亮区积分最大就作为定位点。该拟合假设单个紧凑聚焦点，
复杂光环、多峰或严重离焦仍可能被拒绝，不代表能修复光路。

- 中心有限饱和时，排除近饱和像素，利用外围拟合中心；候选包围框内饱和比例最多 35%，
  外围需覆盖至少 7/8 方向，归一化拟合残差不超过 0.18。再移除拟合峰值的内层数据重拟合，
  检查中心漂移。不是直接删掉饱和像素再计算重心。
- `geometry_spot_max_fwhm` 控制最大半高全宽（原始相机像素），0 为自动：原始帧短边
  的 4%，限制到 12～160 px；可手动设置至 512 px。半高全宽不是目标 ROI 尺寸。
- `geometry_spot_stability` 默认 1 px，同时约束两种外围拟合中心和重复采集中心的变化。
  `geometry_repeats` 默认 2，每次仍按当前平均帧数采集；可设 1～5，1 次跳过跨采集稳定性检查。
  每个点通过后取各次中心的均值，9 个拟合点、5 个局部独立验证点及 8 个目标边缘验证点分别处理。
- 搜索 ROI 可在第三页原始 CCD 细节预览上绘制，然后在子窗口点击“读取第三页 ROI 为搜索区域”。
  此固定区域必须覆盖所有定位点；逐点辅助的临时框只用于当前点。相机身份、分辨率和采集几何会在开始前核对。
  搜索框不修改硬件 ROI，也不代替标定最终输出的目标四边形。清除后恢复全画面搜索。
- `compact_signal.png`、`diagnostics.json` 记录候选拟合与拒绝原因；重复采集保存在
  `probe_XX_repeat_01` 等目录，`probe_XX/repeatability.json` 保存跨采集稳定性检查。
  失败仍保留原始帧与诊断。旧标定不会因升级检测器自动变得可靠，应重新标定。
- 回环、模型标定仍严格检查目标区域近饱和比例超过 1%；错误增加实际比例与阈值说明。
  几何定位允许有限饱和并不表示这些强度数据能用于光度训练。

#### 文件说明

几何标定每次采集会保存 `captures/background/raw_preview.png` 或
`captures/probe_XX/raw_preview.png`，使用固定白电平缩放，原始分析数据仍为 `raw.npy`。
多帧平均设置生效时，保存的是平均采集数组。
每个定位点额外保存差分图 `difference.png`、平滑差分图 `difference_smoothed.png`、
阈值掩膜 `candidate_mask.png`、候选标注 `candidates.png` 和 `diagnostics.json`。
定位失败也保留文件，日志给出目录，`captures/README.txt` 解释数值与颜色。
诊断保存定位算法的实际差分、阈值和候选。
标注为原始相机像素坐标：绿=通过，橙=第一候选但未通过，红=其他候选。
PNG 仅便于查看；差分图按单张最大值拉伸，不应直接跨帧比较其亮度。
将训练入口迁移到另一台电脑时应更新整个 `tools/holography` 目录，包含 `diagnostics.py`。

### 分阶段曝光、内置目标与范围预检

- 目标计算宽、高各支持 16～4096；1024 是旧软件上限，不是硬件限制。
  增大目标计算尺寸不会自动增加物理视野，也不能补出传播网格未解析的细节。
  目标页面可选择图像文件、粗线十字、方框或非对称 L 与圆点；内置图案直接生成目标强度，
  参数可保存，训练目标仍导出为 target.png。界面预览限制为最长 1200 点，训练保留完整尺寸。
- 目标页面提供“目标按参考物理尺寸 1∶1”。相机中继成像倍率独立设置，
  只影响目标在 CCD 上的大小；例如 8640×4860 μm 目标经 0.5 倍成像后为 4320×2430 μm。
  映射采用实测矩阵，不会重复乘倍率。传播段内的透镜需要对应传播模型，不能当作中继缩放处理。
- “几何标定与 ROI”可独立设置局部探测宽高（geometry_independent_range、geometry_width_um、
  geometry_height_um）。“调整标定探测范围”仅缩小局部范围并保留 2% 余量，
  不改变目标尺寸、尺寸设置模式、传播距离或硬件有效区；“探测范围匹配目标”恢复相同宽高。
  参数文件保存这些字段；旧配置默认跟随目标范围。
- 新几何结果 schema=2，单独保存 local_validated、probe_size_um、target_validation。
  9 点拟合、5 点局部验证后，另用 8 个目标边缘点验证完整目标，并检查 CCD 覆盖。
  边缘带宽超限、定位失败、误差超限或 CCD 覆盖不足时，保留局部结果，禁止应用于完整目标回环。
  不以外推的矩形范围代替完整目标验证。原始预览红色实线显示目标 ROI，蓝色虚线显示探测范围。
  手动框选只限制定位搜索区域，不决定目标 ROI。旧 schema=1 保留原有校验，但界面提示边缘未验证。
- 在“成像与采集”勾选“按阶段固定曝光”，分别设置几何标定曝光、重建与回环曝光。
  未勾选时沿用主界面当前固定曝光，旧参数文件保留此行为。
  “读取当前曝光”从 SDK 最近返回值填写；“应用重建预览曝光”在空闲时固定曝光并关闭自动曝光。
  相机回环和模型标定全程使用重建曝光，几何任务初始使用标定曝光；辅助重拍可单独调整曝光，结束/失败/取消恢复原曝光。
  应用生成相位时，若开启分阶段曝光且相机已连接，也会请求重建预览曝光。
- 几何映射复用只忽略相机曝光、增益和自动曝光状态；相机身份、分辨率、ROI、方向等仍严格匹配。
  光度模型仍比较完整硬件条件，曝光变化不能直接复用不同曝光下的光度模型。

### 采集后逐点框选辅助

“几何标定与 ROI → 定位辅助”提供三种模式（旧配置默认全自动）：

- **全自动**：按固定搜索范围定位，失败时停止并保留诊断。
- **逐点手动辅助**：加载定位相位并采集后暂停，自动显示第三页，冻结本次实际用于定位的图像。
  框住当前光斑及完整外围，留出余量，点击“确认框选并继续”。程序在框内精确拟合中心，
  同一点的重复采集复用这个框；下一定位点重新选择。不需要一个框覆盖所有点。
- **自动定位，失败时手动辅助**：正常自动完成，仅检测失败或重复位置不稳定时进入第三页。

冻结图是保存的 `raw.npy`（按采集平均帧数设置生成），不是之后到达的实时预览。
等待框选时相位保持，后台相机仍采集；可平移、缩放、重画框，不能解冻替换本次定位图。
确认后仍检查光斑形状、有限饱和、外围完整性、重复稳定性和最后的独立点验证。
手动框选不会绕过这些检查，也不改变硬件采集 ROI 或标定输出的目标四边形。

框内定位失败会再次暂停，可以重画框分析同一张图，也可以设置曝光后点击“按此曝光重拍”。
重拍会更新同曝光平相位背景，再采集当前定位点的全部重复帧；此曝光沿用于后续定位点。
之前的采集、失败诊断和框选记录不会覆盖：重拍目录带 `_retry_XX`，重新分析带 `analysis_XX`，
`selection_XX.json` 保存操作及框选，`diagnostics.json` 记录所用背景，`repeatability.json` 记录重复检查。
重复位置不稳定时重新框选会重新采集该点的整组重复帧。

第三页可直接“停止标定”；失败、取消和完成仍恢复原显示与曝光。
临时框选结束后恢复此前的 ROI 和冻结状态；若原本实时预览，则恢复最新帧。
跨电脑更新需要同时更新 GUI、UI 和整套 `tools/holography`，只替换 `worker.py` 不够。

### 圆环定位与曝光准备

- `geometry_detector=ring`：粗选中心及完整内环后，先拟合梯度方向，再细化 180° 中心对称性；
  检查角向覆盖、明暗交替、内外圈中心差和跨采集稳定性。保留 `spot` 亮斑模式。
  `geometry_ring_radius` 是原始相机像素，默认 100，不使用光斑 FWHM 限制。
- `geometry_probe=focus/disk/axicon`：聚焦相位、固定 π 圆形相位区、固定轴锥；后两者叠加
  `2π(x·dx+y·dy)/(λz)` 相位斜坡，在菲涅尔近似下平移传播图案。圆形相位区不是振幅光阑。
  固定图案没有在 SLM 面上移动；映射仍使用所设目标平面的模型坐标，绝对尺寸需要外部物理参照。
- `geometry_movement_check` 默认开启：先中心/左右/上下五点检查，再九点拟合、五点独立验证。
  位移不足、两轴退化、非一致移动停止；指标写入 `movement_check.json`，不会应用失败的映射。
- `geometry_auto_exposure` 默认关闭以保留手动行为。开启后通过实际首个探测图像反馈调节曝光，
  保持增益不变，默认平滑峰值目标为满量程 65%，连续两轮合适后锁定并重采背景。
  这是程序的图像反馈曝光，不是 SDK 全画面 AE；曝光范围和实际读回由 SDK 提供。
  相位 SLM 全白并不是“最大透光”，因此不靠全白画面预测聚焦/环纹亮度。
  `exposure_preparation.json` 和 `captures/exposure_*` 保存过程；失败/取消恢复原硬件状态。
- 准备只保证首个探测位置的亮度；后续位置仍需通过检测与重复验证。曝光不是定位阈值。
  重建/回环曝光与光度饱和检查不变。建议现有环纹先选聚焦相位、圆环中心、逐点手动辅助。
