# MainWindow 光学控制台

界面文件为 `MainWindow.ui`，窗口类及 objectName 均为 `MainWindow`。运行控制器位于 `tools/gui/main_window.py`；Qt Designer 仍可直接编辑界面。

## 启动

以下安装、启动和打包命令均在 `tools` 目录执行：

```powershell
python -m pip install -r requirements-gui.txt
python .\apps\optical_control.py
```

不连接设备的演示模式：

```powershell
python .\apps\optical_control.py --demo
```

如果当前位于项目根目录，也支持：

```powershell
python .\tools\apps\optical_control.py --demo
```

以上两种方式使用同一个入口；直接运行文件时会自动定位项目根目录。

载入保存的配置：

```powershell
python .\apps\optical_control.py --config ..\output\optical_config.json
```

本机的 `xwq` 环境及 `D:\software\python31011\python.exe` 均已检查过 PyQt5、NumPy、Pillow、OpenCV 可用。其他环境缺少依赖时，使用上面的安装命令。

## CCD 细节预览采集与保存

第三页“CCD 细节预览”的右侧提供“采集与保存”：可直接保存单帧、开始/停止录像，并输入或浏览选择保存目录。键盘输入后按回车或离开输入框应用，目录不存在时自动创建；输入无效时提示并恢复原目录。目录与第一页共用，连接相机后也可更换，保存配置时会保留新目录。第二、三页控制同一个相机和录像任务，按钮及保存计数同步。ROI 框、拖动控制点和名称采用醒目的红色。

目录变更作用于后续提交的采集及新录像；已排队的采集和正在录制的视频仍写入原路径。保存单帧采集新的完整图像，不截取缩放视口或 ROI 标注；冻结只影响细节预览，录像和采集继续使用实时画面。图像格式、位深及录像格式沿用第二页的现有保存流程。

第二、三页均提供“单帧另存为…”，可选择本次 PNG 的目录和文件名，不改变默认保存目录，同名文件需单独确认覆盖。第二页始终采集新帧；第三页实时预览时采集新帧，冻结时则锁定打开对话框时的完整冻结帧，使用该帧的旋转、翻转设置并保留位深。缩放、平移及 ROI 标注不会写入图像。冻结帧在独立后台线程中编码保存，关闭程序会等待保存结束。

## 连接初始化、重新导入与测试图案

普通显示器 DMD、SLM1、SLM2 无需输入图像即可通过连接参数检查。连接成功后先发送全屏零灰度；已有输入通过图像检查后，再自动显示第一张，不触发采集。输入缺失、损坏、超出面板或双 SLM 不配对时仍保持连接，显示全黑并在预览卡片提示原因。

连接后通过第二页各设备右侧的“导入图像…”选择单张图像或目录，无需断开。连接参数页继续锁定设备编号、SDK 等参数。重新导入会暂停相关播放和同步采集，检查整组图像后立即显示第一张，并更新保存配置中的输入路径。双 SLM 联动时对话框依次选择两路输入，名称和数量匹配后一起应用。格式或尺寸检查失败时保留旧序列；SDK 显示失败时尝试恢复旧画面，恢复失败则提示重新连接。

“测试图案…”可手动发送全黑、全白、棋盘格，或恢复当前输入图像。测试图案覆盖整个实际面板，暂不使用输入图像的旋转、翻转、偏移和灰度转换；不会修改这些参数，也不会替换正式输入序列或触发自动采集。全黑表示零灰度相位输入，不代表关闭光束。F4321 仍要求有效输入并使用原有上传流程，这两个按钮对它不可用。

## 单 SLM 全息测试与相机同步采集

1. 参数页启用 SLM1 或 SLM2 和所需相机，关闭不用的硬件，载入相位图序列并连接。
2. 第二页在“SLM 同步采集”下拉框选择对应的 SLM，设置旁边的稳定时间（默认 0.5 秒）。只启用一个 SLM 时不会进行双 SLM 联动；两路都启用时，如需独立播放，请在连接前取消“双 SLM 同步播放”。
3. 点击该 SLM 的“播放”或“开始运行”。程序加载相位图、等待稳定、丢弃稳定后的首帧，再保存采集图；保存成功前保持当前相位图。
4. 相位图 `phase_001.bmp` 对应保存目录中的 `phase_001.png`。PNG 保持相机采集位深，并使用当前相机旋转/翻转设置。启用采集记录时，`captures.jsonl` 会记录相位源文件、同步来源、显示参数和相机帧信息。

播放间隔是最短停留时间。若采集或磁盘写入较慢，等待保存成功后在后续播放时刻切换，不跳过未完成的图案。稳定时间可大于播放间隔。超时或写入失败会暂停该序列；不勾选“覆盖同名文件”时，同名输出已存在也会暂停并提示，不覆盖原文件。

DMD 同步采集与 SLM 同步采集互斥。双 SLM 同步播放时也可选择一个 SLM 作为采集命名来源，每一对图案只采集一次。手动“保存单帧”仍使用时间戳名称，不影响同步序列。暂停、停止全部、切换帧或断开连接会取消尚未完成的同步采集。

这是软件控制的逐图采集，不是相机外触发同步。demo 仅验证播放、保存和命名流程，图像来自合成相机，不代表真实光学效果。

## 干净环境与自行打包

`tools/requirements-gui.txt` 覆盖 `tools` 自有 GUI、设备封装、命令行及图像处理代码的 pip 运行依赖，并包含 PyInstaller 构建工具。运行依赖为 PyQt5、NumPy、Pillow 和 opencv-python；各包的传递依赖由 pip 自动安装。该清单不覆盖 `3rdparty` 内厂商示例或主项目的训练、推理代码。

可按已验证的 Python 3.10 创建独立 Windows 64 位环境，在 `tools` 目录执行。已有 `(pyqt)` 环境时跳过前两行：

```powershell
conda create -n optical-tools python=3.10 pip tk -y
conda activate optical-tools
python -m pip install -r requirements-gui.txt
python -m pip check
python .\apps\optical_control.py --demo
```

`tk` 为部分 DMD 命令行工具提供 Tkinter/Tcl/Tk；Qt 主界面使用 PyQt5。Tkinter、ctypes、msvcrt、unittest、json 等随 Python/其运行环境提供，不应作为同名 pip 包加入清单。自动标定在打包版中导入预先训练好的相位包，无需 PyTorch。仅本地开发训练额外安装 `calibration/requirements.txt`。硬件配置使用子项目 JSON，不引入 PyYAML；SciPy 和 pywin32 也不因此成为依赖。

### 在 tools 目录打包 GUI

使用现有的 `tools/Qing.spec`。它配置了目录模式、`Qing.exe` 名称、`lib` 依赖目录、界面及 `QIC.ico`，并排除 PyTorch 和开发训练模块。准备打包时在 `tools` 目录执行：

```powershell
python -m PyInstaller --clean .\Qing.spec
```

spec 根据自身目录定位入口、项目根目录和资源，不依赖启动命令时的工作目录。`tools/ui` 是包内资源目标路径，位于输出的 `lib` 目录下。生成后先检查演示模式：

```powershell
.\dist\Qing\Qing.exe --demo
```

发布时携带整个 `dist/Qing` 文件夹。打包配置统一维护在 `Qing.spec` 中，仅新增子项目自己的 `calibration_config.json` 数据文件，发布后位于 `lib/tools/calibration_config.json`，可独立修改。GUI 源码运行和打包不需要主项目 YAML 或额外解析文件，spec 明确排除 yaml、models、PyTorch 与开发训练模块。已有 EXE 不会随源码修改自动更新，需要重新打包。真实硬件连接时，在参数页为外置 SDK/DLL 选择绝对路径，并将输出目录设置到可写的固定位置。完整标定训练目录另行复制，通过“导入相位包…”选择 `manifest.json`，详见 [标定包训练与使用](../calibration/README.md)。

自行配置打包时需要保留这些资源和路径（下面的源码位置按项目根目录描述）：

- GUI 入口：`tools/apps/optical_control.py`。PyInstaller 的模块搜索路径包含项目根目录，并显式收集 `tools.gui.main_window`，避免入口的相对导入被静态分析遗漏。
- 界面：将 `tools/ui/MainWindow.ui` 作为数据文件收集到包内同名路径 `tools/ui/MainWindow.ui`。
- 硬件库：SLM、CCD 和 F4321 SDK 由 ctypes 按配置路径加载。按原有目录结构收集实际设备所需的 DLL 及配套文件，或在配置页指定外置 SDK 的绝对路径；目标电脑仍需安装厂商设备驱动和运行库。不要修改 `tools/3rdparty` 原始文件。
- 数据目录：打包后将输入、输出和外置 SDK 路径配置为绝对路径。当前相对路径基于包资源根目录解析，单文件模式下该目录可能是临时解压目录，不适合保存实验结果。
- 旧图案生成工具及本地 ASM 训练需要主项目 `models`，只在开发环境使用。上面的 GUI 打包命令排除 `models` 和 PyTorch；导入标定包后的设备端流程只使用图像、NumPy 参考数组和 JSON 参数。

PyInstaller 与 hooks 的安装说明见[官方文档](https://pyinstaller.org/en/stable/installation.html)；资源位置和手动收集 DLL 的规则见[运行时路径](https://pyinstaller.org/en/stable/runtime-information.html)与[ctypes 依赖](https://pyinstaller.org/en/stable/feature-notes.html#ctypes-dependencies)。本次仅整理依赖和打包说明，未生成或验证 EXE。

## 使用流程

自动标定入口位于两页工具栏，使用步骤和限定光路见 [自动标定说明](../calibration/README.md)。打包版通过“导入相位包…”载入训练目录的 `manifest.json`，读取原始相机帧，验证通过后应用方向和偏移。本地开发模式另提供“仅训练相位图”；demo 棋盘格只用于预览。目前尚未实物验收。

1. 初始页面填写实验名称、保存目录、各设备输入及 SDK 路径。只勾选这台电脑实际连接的设备。
2. 通过“浏览…”选择文件或目录。DMD、SLM1、SLM2 输入载入后即可在第二页本地预览；未连接时的播放按钮只更新本地预览。
3. 点击“枚举设备”查看 Windows 显示器编号、MagicHolo SDK display ID 和相机编号，再点击“检查参数”。
4. 点击“连接设备”。界面会锁定连接参数并切换到预览页；CCD 在后台开始连续取帧。连接后读取相机实际曝光及增益，不自动写入界面初值。
5. 点击“开始运行”发送首帧并播放。也可单独控制某一设备。启用“双 SLM 同步播放”时，两路相位文件必须具有相同主干名称及顺序，共用 SLM1 播放间隔和帧索引。
6. 需要随 DMD 输入逐帧采集时，勾选位于“双 SLM 同步播放”左侧的“DMD 同步采集”，再播放 DMD。默认不勾选；未勾选时只播放，不自动保存相机帧。播放中锁定该开关，暂停后可切换。
7. CCD 连接后可“应用”曝光 / 增益、“保存单帧”“开始录像”。ROI 在配置页设置，修改后需重新连接。
8. “停止全部”停止图案播放、待处理的自动保存及录像，CCD 预览继续；“断开设备”或关闭窗口停止采集并释放设备。DMD 输出窗口按 Esc 也会断开设备。

## 画面与采集行为

### 第三页：CCD 细节预览与 ROI 标注

第三页复用当前相机和采集线程。连接 CCD 后，在第二页选择“1:1 像素”会自动打开第三页；也可直接点击“03 CCD 细节预览”。未收到相机帧时，图像及标注操作不可用。

1. 用滚轮或加减按钮缩放，或输入缩放百分比；“适应窗口”显示完整图像，“1:1 像素”让一个原始图像像素对应一个屏幕物理像素，已考虑 Windows 高 DPI 缩放。
2. 选择“平移”，按住左键拖动画面。也可点击或拖动右侧全图导航，移动查看位置；导航中的轮廓表示当前可见区域。
3. 选择“框选 ROI”并拖动，生成一个矩形标注。开始绘制、移动或调整大小时自动冻结当前预览，后台采集、保存和录像继续；点击“恢复实时”查看最新帧。
4. 在框选模式下，拖动矩形内部可移动 ROI，拖动四角或边中点可调整大小。也可输入名称、X/Y、宽/高，点击“确认 ROI”。`Esc` 取消当前拖动，`Delete` 或“清除 ROI”移除标注。
5. “保存标注…”写入 JSON；“载入标注…”读取并检查匹配关系。标注文件记录原始帧尺寸、像素位深、相机信息、硬件采集 ROI、矩形坐标，以及当前参考帧号和显示方向。文件只保存标注与元数据，不保存图像本身。
6. “返回四路总览”回到第二页。取消“第二页选 1:1 时打开此页”后，第二页保留原有居中 1:1 预览；该偏好随实验配置保存。

标注坐标始终以**原始采集帧左上角**为原点，矩形为 `(x, y, width, height)`，覆盖列 `x` 到 `x+width-1`、行 `y` 到 `y+height-1`。显示跟随第二页 CCD 的旋转和翻转，ROI 随图像一起变换，保存的坐标仍对应原始像素。鼠标位置和像素值也来自原始帧，彩色帧标明 BGR 顺序；高位深像素读数保留原值，预览亮度仍按现有方式转换。

此 ROI 是图像标注，不写入相机 SDK，也不会自动裁切采集文件。第一页的硬件 ROI 仍控制实际采集范围；硬件启用裁切时，标注原点对应返回帧左上角。载入标注时检查图像尺寸、可用的相机型号/序列号及硬件 ROI；范围越界或不匹配会拒绝载入，保留现有标注。

实时帧尺寸改变时清除旧 ROI，并按新尺寸更新坐标范围。冻结时保留冻结帧、方向及标注，恢复实时后才处理新尺寸；断开或重新连接相机会清空旧画面和标注。第三页未打开时仅保留最新帧，避免持续生成大画布与缩略图；冻结时额外保留当前显示帧，不积累历史帧。

实现位于 `gui/ccd_detail.py` 和 `gui/ccd_detail_view.py`，无需新依赖。界面与交互已用模拟相机和合成高分辨率/高位深帧检查，真实硬件与显示器仍需实机确认。

### 已接入的预览与采集

- 第一页为参数配置；第二页按 2×2 显示 DMD、SLM1、SLM2、CCD，每张卡片左侧为大预览，右侧为参数和操作。正方形、横向、竖向图像均保持宽高比。
- DMD、SLM1、SLM2 面板标称均为 1920×1080；640×640、432×432、768×768 是当前常用的有效输入区域，不是面板分辨率。界面根据实际输入显示有效区尺寸，连接后根据设备枚举值显示面板尺寸。
- 默认“有效区域”只放大输入图案，便于检查细节；切换“完整面板”查看黑底面板中的位置与偏移。两种模式均支持“适应窗口”或“1:1 像素”，只影响预览，不改变硬件输出。CCD 直接显示实际采集图像。
- DMD 使用独立 Qt 全屏窗口按原始像素居中输出，不再启动 Tkinter。SLM1 和 SLM2 调用原有 ctypes SDK 封装。两片 SLM 均提供 X/Y 偏移和应用按钮，偏移单位为面板像素，相对居中位置计算，越界会拒绝发送。中科 SLM1 用完整黑底画布实现内部偏移，显示窗口保持在原面板位置；SLM2 使用原有全尺寸灰度画布。
- 同时启用 DMD 和 CCD 并勾选“DMD 同步采集”后，DMD 播放每帧时会在稳定时间之后请求一张新相机帧，保存为 DMD 同名 PNG。采集超出该图案的显示窗口则报告超时，不把过期帧保存到下一张图案名下。
- 这是基于软件计时的采集，不是硬件触发。相机内部缓冲与曝光时序仍需实机标定。双 SLM 与 DMD 各按设置间隔运行；双 SLM 同步选项只同步两片 SLM。
- 手动保存使用时间戳和随机后缀。默认拒绝覆盖文件；循环播放时，同名自动保存也遵循“覆盖同名文件”选项。
- PNG 保存相机原始通道与位深。AVI 使用 MJPG、20 FPS 和 8 bit 预览图像，适合回看；实际采集帧率不足时，AVI 时间长度不代表精确实验时长。
- 勾选“保存采集记录”会在输出目录追加 `captures.jsonl`，记录文件名、相机帧号、曝光、增益、图像格式及当时的输入图案。
- DMD 和 SLM 画面显示软件发送的图案，不是从调制器读取的光学反馈。CCD 显示相机采集帧。

## 预览刷新间隔

第二页的预览 FPS 按约一秒内实际更新的图像数量计算平均值，数字约每秒刷新一次；图像继续按设置的刷新间隔更新。未收到新图像的统计周期显示 0.0 FPS，断开后清空统计。

第一页相机配置中的“预览刷新间隔”控制界面读取最新相机图像的频率，范围 1～1000 ms，默认 33 ms。可在连接前设为 10 ms，以约 100 次/秒的目标刷新预览；实际 FPS 取决于后台供帧和图像处理、绘图耗时。已连接时需先断开，再修改这一参数。

此参数会随配置保存和载入；旧配置缺少该字段时使用 33 ms。修改后定时器直接使用新值，无需重启源码程序。它不设置相机采集帧率或录像帧率，也不保证达到相机标称最大 FPS；当前录像仍为 20 FPS。使用此前打包的 EXE 时，需要重新打包才能获得这个控件。

配置页和预览页已标注当前相机型号。它是 USB3.0 彩色全局快门 CMOS 相机，标称分辨率 1280×1024、像元尺寸 4.0 μm；原有界面中的“CCD”继续作为采集通道简称。参数参考[度申官方产品资料](https://en.do3think.com/product/m3st130-h-o2c-area-scan-camera)（英文站型号写作 M3ST130-H-O2C；未连接时按当前设备标注使用 02C，连接后显示 SDK 实际返回值）。

- 继续使用现有 DVP2 SDK 与采集线程，无需新增依赖或单独安装同名 Python 包。兼容性仍需使用已安装的厂商驱动和实机验证。
- 默认 `bgr8` 输出彩色图，每通道 8 位，即 BGR24；选择 `mono8` 时请求 8 位灰度。`native` 沿用相机当前输出格式，不会自动设置最高位深；PNG 保存收到的数据位深，AVI 仍使用 8 位 MJPG。
- ROI 默认关闭。640×640 是勾选 ROI 后的裁切初值，不是相机原生分辨率；程序根据实际帧尺寸显示和保存，不强制裁成 640×640。ROI 对齐、曝光和增益是否合法由 SDK 检查，不将网页参数写成固定的软件限制。
- “枚举设备”显示实际型号和序列号；连接后预览标题显示 SDK 型号，标题提示中显示序列号。启用采集记录时，`captures.jsonl` 的 `camera` 字段也记录实际型号、序列号、设备名称和厂商。
- DMD 同步采集仍使用软件计时，当前未接入相机硬件触发。预览刷新和录像速率也不等于相机标称最高采集帧率。

本次仅更新这一台相机的标识与设备信息，另一台大靶面相机尚未加入。

## F4321 DMD 与共用输入转换

第一页新增独立的“DMD · F4321 高速控制器”硬件卡，原有 DMD 保留为显示输出设备。两种 DMD 每次启用一种，勾选其中一种会取消另一种；它们各自保留输入路径，并共用第二页 DMD 预览和控制。

1. 启用 F4321，选择图像文件或目录、`F4321_HS.dll`。默认 DLL 位于 `tools/3rdparty/F4321_HS_FG/DLL_Python_2`，要求 Windows 64 位 Python。新增封装无需额外 pip 包。
2. 本机 IP 填实际连接 DMD 的网卡 IPv4 地址，目标 IP/端口填控制器设置。设备 ID 为 SDK 内部的 1～3，与 Windows 显示器编号无关。预填网络值只是示例。
3. 在共用转换卡选择“8 位灰度”或“1 位二值”。“保持原图”只适用于原有显示输出 DMD。二值阈值按转换后的 0～255 灰度计算；启用抖动时使用 Floyd–Steinberg 算法，阈值不参与计算。
4. 默认按源位深映射：8 位范围为 0～255，16 位为 0～65535，不对每张图单独拉伸。自定义范围将黑、白电平映射至 0 和 255，并截断范围外的值。浮点或无法判断有效位深的整数图需要自定义范围；彩色图先转亮度灰度。
5. 连接时先查询实际面板尺寸及就绪状态，再在临时目录生成 BMP 副本并后台上传。每张图先转换位深、翻转、旋转，再按原始像素居中填入完整黑底面板。尺寸超出面板会拒绝上传，不自动缩放或裁切；输入文件始终保持不变。
6. 上传完成后使用第二页的上一张、下一张、帧号、播放、暂停及旋转/翻转。修改方向会暂停播放并重新上传整个序列；“重新上传”可重新读取源文件。上传时可取消，失败后按提示断开再连接。

**时间设置：** 第一页的曝光、暗场时间为板载灰度图的周期参数（界面单位 µs，SDK 单位 5 ns）；第二页的播放间隔控制应用多久切换到下一张输入图，不能短于曝光与暗场时间之和。程序将一张 8 位图作为八个二值位面循环输出，到下一次软件切换时才更换图像。“暂停”暂停切图和自动采集，保留当前图像的板载循环以维持灰度；“停止全部”或断开设备才发送控制器停止指令。DMD 与 CCD 仍使用前述软件同步采集，未接入 F4321 外部触发和高速整段序列采集。

程序等待设备的接收反馈后才允许播放；仅 UDP 初始化成功不会标记设备在线。接收超时会显示预期数据量和最后反馈。取消或上传异常会先释放 SDK 再清理临时 BMP；如果 SDK 释放失败，保留文件与连接对象供重试断开，避免厂商线程仍在读取时删除文件。普通断开不会发送需要重新上电的 Float 指令。

新增流程已用模拟 SDK 验证；本机未连接 F4321 实物，设备固件反馈、实际曝光和光学显示效果仍需实机验收。

SDK 会保留查询缓存，因此断开时在 `DeInit` 成功后释放 DLL，重新连接时重新加载。上传前检查临时目录枚举顺序，避免厂商按目录顺序读取 BMP 导致帧号错配。上传完成反馈 `Rec Pic Data Num` 当前按图像有效载荷字节数严格校验；厂商文档未明确该字段单位，此处仍需实板核对。若固件反馈不同，程序会报接收超时并保留反馈文字，不会将缓存标记为可播放。

## ToupTek 相机

第一页下方的 `ToupTek / IUC26000KMA` 卡片已接入 SDK。勾选启用会取消度申相机；确认 DLL 路径后枚举并选择设备、分辨率，再连接。单台相机允许自动选择。连接后显示 SDK 实际型号、序列号和像元，第二页及第三页复用当前相机帧。

支持单色 RAW 8/16 位、SDK 支持的硬件平均 Binning、软件平均 Binning、LCG/HCG、传感器 ROI、曝光 / 增益和自动曝光。PNG 保留采集位深，AVI 仍为 8 位 MJPG。最大分辨率及能力按设备读取，未访问设备时不把参考参数显示为实测结果。详见 [ToupTek 接入说明](TOUPTEK_DESIGN.md)。

当前相机显示只刷新可见页面；第二页适应窗口时降采样显示，第三页像素查看、保存数据仍用完整采集帧。相机自动标定暂限原生分辨率、关闭 Binning 与硬件 ROI，并核对实际像元间距。`Qing.spec` 已包含 ToupTek DLL，但此次未打包。

## 图像旋转与翻转

第二页四个设备均可独立设置旋转角度、水平翻转和垂直翻转。修改角度并按 Enter 或移开焦点后应用；翻转勾选后应用。默认角度为 0°，正值顺时针，负值逆时针；水平翻转是左右镜像，垂直翻转是上下镜像。

- 顺序为：对原图水平/垂直翻转，再绕图像中心旋转，最后居中放入固定面板并应用 SLM 偏移。背景画布和显示窗口的位置保持固定，修改多次都从原图重新计算。
- DMD 的实际全屏输出、SLM2 的 SDK 像素缓冲区、SLM1 交给 SDK 的临时图像都使用变换结果。预览和设备输出使用同一变换算法；有效区尺寸显示旋转后的外接矩形。
- 任意角度旋转会扩展有效区，空白处补背景。采用最近邻采样，避免插值产生新的相位灰度；直角旋转和翻转是精确像素重排。斜角仍有像素采样造成的锯齿或重复，不能代替物理像元的旋转。
- 旋转后及偏移后必须完整容纳于面板，不自动缩放或裁切。例如 640×640 旋转 45° 后约为 906×906，可以放入 1920×1080；768×768 旋转 45° 后约为 1088×1088，会超过面板高度并拒绝应用。修改失败会恢复先前角度/翻转状态，保留原预览。
- CCD 在获取真实相机帧后执行软件变换，预览、保存 PNG 和录像方向一致；PNG 保持原始位深和通道，录像继续使用原有 8 bit MJPG 编码。相机传感器 ROI 和原始采集尺寸不变，PNG 与录像尺寸可能随旋转扩展。采集记录包含变换参数、原始尺寸及输出尺寸。
- 对应设备播放时锁定方向控件；双 SLM 同步播放时同时锁定两路。DMD 同步采集运行期间锁定四路方向；CCD 录像期间锁定 CCD 方向，停止后可改。修改 CCD 方向会取消尚未完成的保存请求并提示，避免保存到错误方向。
- 方向参数随 JSON 配置保存；旧配置未包含这些字段时使用 0°、不翻转。仅在未连接时可载入配置。

当前变换已接入真实硬件调用路径，并通过模拟 SDK 接收数据的测试；实际设备显示效果和实验光路仍需在现场验证。

## 参数和设备约定

- 相对路径统一以项目根目录解析；厂商原始文件仍在 `tools/3rdparty`，未改动。
- DMD / SLM1 使用设备枚举中的 Windows monitor 编号，SLM2 使用 SDK display ID，两者不能互换，也不能直接照搬 Windows 设置中的屏幕编号。枚举窗口根据坐标和分辨率列出两套编号的对应关系。
- SLM2 自动选择优先识别非主屏、1920×1080 的 HDSLM / MagicHolo 名称；未返回此类名称时，仅在该分辨率的副屏唯一时回退选择。多个候选时要求手动指定 SDK ID。
- 连接时先确定 DMD、SLM2，再为 SLM1 自动选择剩余的唯一副屏；没有候选或仍有多个候选时明确报错。中科 SDK 当前没有提供可用于识别 SLM1 型号的显示器名称，因此必要时仍需手动选择。选择到相同显示区域会拒绝连接，连接状态文字的悬停提示显示实际选择的编号和坐标。
- 仅在勾选“DMD 同步采集”时要求 DMD 稳定时间小于播放间隔，并等待相机第一帧后才允许开始同步播放。SDK 拒绝的曝光、增益、ROI 或偏移会显示错误；ROI 对齐和参数范围以实际设备为准。
- Windows 显示输出使用物理像素；建议将对应扩展显示器设置为原生分辨率和 100% 缩放。
- 保存/载入配置使用带版本号的 JSON。连接状态下禁止载入配置或修改连接参数，需先断开。
- 演示模式生成临时示例图案，CCD 帧带 `DEMO - NO CAMERA` 字样。它不会调用厂商 DLL，也不会在真实设备连接失败时自动启用。保存的记录中包含 `demo: true`。演示输入位于临时目录，不应作为长期实验输入路径。

## 代码结构

```text
tools/
  apps/optical_control.py       # 启动入口、--demo、--config
  gui/main_window.py           # MainWindow 控制器与播放调度
  gui/configuration.py         # 配置序列化、图像与 Qt 转换
  gui/displays.py              # Qt DMD 窗口及两种 SLM 适配器
  gui/dmd_backends.py          # DMD 类型与适配器选择
  gui/f4321_display.py         # F4321 图像暂存、上传与预览接口
  gui/device_task.py           # 设备连接、上传后台任务
  devices/f4321_dmd/           # F4321 ctypes SDK 与缓存播放控制器
  utils/dmd_images.py          # 两种 DMD 共用的位深/灰度转换
  gui/camera_worker.py         # 单独线程中的 CCD 取帧、参数、保存、录像
  ui/MainWindow.ui            # Qt Designer 布局
  requirements-gui.txt         # GUI 可选依赖
```

相机 SDK 调用集中在同一个工作线程。GUI 按配置的预览刷新间隔读取最新一帧（默认 33 ms，约 30 Hz），避免慢渲染造成消息积压。断开和关闭窗口会等待线程释放相机，不强制终止 SDK 线程。

# 全息子窗口

`HolographyWindow.ui` 是可用 Qt Designer 编辑的独立子窗口，主界面两页均有
「全息生成…」入口。保留控件 objectName 即可修改布局；控制层在
`gui/holography_window.py`，训练与优化由外部 Python 进程完成。
支持单 SLM1、单 SLM2、双 SLM，以及离线生成、相机回环和传播模型标定。
五个参数页分别为目标与尺寸、光路与训练、成像与采集、几何标定与 ROI、文件与环境。
自定义参考宽高采用 px，使用参考像素间距换算；相机方形像元共用一个尺寸输入。
标题栏「?」和 F1 均打开本地可搜索帮助；帮助界面为
`HolographyHelp.ui`，正文为 `holography_help.html`，可独立编辑，已列入 Qing.spec。
