1. 先做什么

  • 全息生成（离线）：选择目标图、SLM、物理尺寸和传播参数，配置外部 Python 环境后点击底部「开始」。无需连接设备；完成后得到相位文件和模拟重建，尚不能代表实物效果。
  • 相机回环优化：先连接所选 SLM 与相机，固定照明和曝光，完成相机坐标映射。程序交替加载相位、采集新帧、优化，再进行最终实拍验证。
  • 传播模型标定：先完成几何映射，再采集多组灰度相位和实拍数据，拟合有效光源振幅、相位响应及像差。通过留出样本验证后，才可载入模型文件用于生成。

单 SLM 的推荐顺序：机械粗调 → 连接所选 SLM 和相机 → 设置目标视野与采集参数 →「开始几何标定」→ 检查验证结果 →「应用映射与目标 ROI」→ 相机回环或传播模型标定。

单层不要求另一片 SLM 或 DMD 连接。任务期间，已连接但未参与的另一片 SLM 会显示全黑；结束或停止后恢复原显示。照明应保持固定；当前传播模型以首片 SLM 有效区内的参考照明为基础。

2. 尺寸、像素与倍率

像素数本身没有固定的物理长度。例如同样 640 个像素，像素间距不同，代表的毫米数也不同。

参考来源如何填写
所选 SLM 有效区域使用「光路与训练」中的有效宽高和该 SLM 的像素间距。双层模式以 SLM1 为参考。
DMD 输入区域填写计划使用的 DMD 输入宽高及 DMD 像素间距。此处不要求连接 DMD，也不自动改动硬件。
自定义像素尺寸填写自定义参考宽、高（px），以及旁边的「参考像素间距」（μm）。程序自动换算物理尺寸，不需要手算。

按参考尺寸 × 倍率：目标宽高 = 参考像素宽高 × 参考像素间距 × 重建倍率。640 × 640 px、5.4 μm、倍率 1，得到 3456 × 3456 μm，即 3.456 × 3.456 mm；换为 500 × 500 px，得到 2.7 × 2.7 mm。

手动输入目标宽高：直接指定目标平面的物理尺寸，不跟随参考尺寸和倍率。页面下方始终显示换算结果。

1:1表示目标物理尺寸与所选参考区域相同，不保证一个输入像素对应一个相机像素。改变自定义尺寸不改变导出的 SLM 相位分辨率；导出尺寸由 SLM 有效宽高决定。

重建倍率与中继成像倍率不同：前者决定希望重建多大的目标；后者描述目标经成像透镜后，在相机传感器上的大小。二者不要混填。

3. 图像适配

「输入图像 / px」只显示原图尺寸。程序在内存中适配目标，不修改原文件。

  • 等比例适应 · 留边：完整保留图像，空余区域填黑，内容比例不变。
  • 等比例填满 · 裁剪：填满目标区域，超出的部分居中裁去，内容比例不变。
  • 拉伸填满：使用整张图填满目标区域；原图与目标比例不同时，内容会变形。

适配依据目标的物理宽高比，而非只看计算数组是否为方形。左侧预览可切换输入原图、当前适配后目标和最近一次训练目标。

4. ASM、控制点与传播距离

  • SLM 有效宽高：实际优化和导出的相位图像素数。有效区不等于整个硬件面板。
  • ASM 网格宽、高：数值传播计算数组的横、纵点数；宽 × 采样间距、高 × 采样间距分别决定两个方向的计算视野。开始任务时分别补足不足的方向，保留已足够的手动值。它包含有效区及外围传播区域，不能简单当作硬件分辨率。
  • ASM 数值采样：计算平面中相邻采样点的物理间距。当前模型共用物理网格，要求不粗于所用 SLM 的像素间距。视野不足时会增大网格，已有较大值会保留；内部还使用零填充。
  • SLM1 / SLM2 控制点宽、高：每片 SLM 有独立的矩形控制点数组。宽高均等于该片有效宽高时，逐像素优化，例如 1920×1080；设为 960×540 时则插值到 1920×1080。减小控制点通常按相同宽高比缩小，增加控制点不会扩大硬件区域。这些参数用于全息生成与相机回环，传播模型标定仍使用其多尺度探测图案。
  • 目标计算宽、高：表示目标与重建强度的横、纵采样点数，不是相机 ROI 宽高，也不决定物理视野。“匹配目标比例”保留计算宽度，按最终目标物理高度 ÷ 宽度计算高度并取整；仅点击时调整。例如 4320×2430 μm 的视野，计算宽度 640 对应高度 360，采样为 6.75×6.75 μm。超出范围时提示调整计算宽度。
  • 传播距离：单层填写所选 SLM 到目标平面的距离；双层还需 SLM1 到 SLM2 的距离。直接采集时目标平面是传感器面，中继采集时是被成像的重建平面。

增大计算网格不意味着光学放大；它增加计算覆盖范围及内存需求。更大的网格或更多控制点也不自动保证更好的实物重建。

计算视野预留倍率：默认 1.5，可设为 1～8。每个方向必须覆盖“SLM 有效物理尺寸 × 倍率”和目标视野中的较大值。1 倍、2 倍只改变计算覆盖范围，不改变重建倍率；ASM 内部仍另有宽高各 2 倍 FFT 补零。

网格单轴上限：默认 4096，可提高到 16384。它是用户设置的资源限制，不是硬件限制，也不是按显存自动计算。提示中的内存只计算一个 FFT 复数数组；实际训练还包括多个中间数组、梯度和工作区，会更高。超限时显示实际所需网格，调整后再开始。

随机相位半范围：例如 0.5 表示从 −0.5～+0.5 rad 随机取值，默认约 π，0 表示平相位起点。以中间灰度对应相位为中心，经当前 LUT 映射到灰度，避免小范围跨越灰度端点。范围仅影响初始化，最终相位不受此范围限制。

GS 初始化：先使用上述随机范围生成起点，再做指定次数的目标振幅约束与反向传播，最后进入 Adam 优化。单层及双层均支持；双层逐片更新。考虑原生像素、控制点、LUT 和像差，是投影 GS 变体。程序保留模拟误差最小的起点，未改善时沿用随机起点，不保证实物效果。初始化不会替换几何标定或模型标定的图案。

5. 相机成像与采集

像元尺寸：方形像元的 X、Y 相同，因此只提供一个输入，手动修改时同时设置两个方向。IUC26000KMA 预设为 3.76 μm；「当前连接相机」优先读取 SDK。未读取到值时保留手动设置，不把未知值自动当作 4 μm。若 SDK 或旧参数中的 X、Y 不同，会保留实际值并显示提示。

采样合并 X / Y（Binning）：与原生像元尺寸不同，两个方向仍可分别核对。名义目标采样 = 像元尺寸 × 总 Binning ÷ 中继成像倍率 |M|。这些是映射参数，不会向 SDK 下发分辨率或 Binning 设置。

  • 直接采集：SLM → 相机，名义倍率为 1。
  • 中继成像：重建平面 → 成像透镜 → 相机，填写倍率绝对值。倒像、旋转和镜像由几何映射处理。
  • 透镜参与全息传播：当前模型尚不支持，不能用成像倍率代替该传播模型。

倍率来源：选择「使用已验证的标定结果」本身不会完成标定；必须先载入并应用有效的几何结果。选择手动初值会退出当前实测矩阵，需要重新确认手动映射。

暗电平、饱和电平：用于解释原始强度，不能随意当作显示亮度调节。8 位通常为 255；16 位容器不一定具有 65535 的有效饱和值。过曝应先降低曝光。

切图后等待、丢弃帧、平均帧：分别控制稳定等待、跳过新帧和平均数量。增加这些值有助于取到稳定图像，但会增加每次测量时间，不会提高相机本身帧率。

6. 几何标定与 ROI

开始几何标定是独立入口，当前支持单 SLM1 或单 SLM2。它生成聚焦定位相位，采集平相位背景、9 个拟合点和 5 个独立验证点。非对称模式也逐点显示，不是同时显示所有点。

映射方式：三种分别做什么，怎样选择？

三种方式都建立目标平面的物理坐标 → 相机原始像素坐标的对应关系，用于确定目标 ROI、方向，以及后续图像提取和对齐。区别在于允许描述的几何变形不同。

界面选项允许校正的变形直观例子
平移 / 旋转 / 镜像 / 等比例尺度（相似映射）位置偏移、旋转、翻转，以及横纵相同倍率的缩放。正方形仍是正方形，只改变位置、方向和大小。
仿射（含横纵尺度、剪切）包含上述变形，额外允许横纵缩放倍率不同，以及剪切。正方形可以变成长方形或平行四边形，平行边仍保持平行。
透视（平面成像）进一步允许平面投影中的透视变形；不包含镜头径向畸变。正方形可以变成梯形，一侧看起来更大，原本平行的边可能不再平行。

选择顺序：先用第一种。如果定位光斑清晰、稳定，但仍存在明显的横纵比例或剪切误差，再尝试仿射。经过成像透镜、目标平面与相机存在倾斜并呈现明显透视变形时，再考虑透视；仅有倾斜不代表一定需要透视模型。

自由度更多不代表更准确。复杂模型可能把不准确的定位点也拟合进去，应比较独立验证点的误差，而非只看拟合点是否贴合。切换映射方式后需重新运行并验证标定，不要通过放宽误差阈值来掩盖定位问题。

映射不能修复光斑质量。这三个选项不改变生成的聚焦定位相位，也不能消除散焦、光圈、零级光或灰度相位响应误差。“大片亮面跟随光斑移动”不能仅靠切换映射方式解决。

允许验证误差的单位为相机原始像素。光斑不足、严重饱和、外围拟合不可靠、多个峰、边界截断、位置不稳定、误差超限或目标覆盖不全时，不允许应用。

红色目标 ROI是指定物理矩形在相机原始画面中的投影，可能为旋转四边形。它不是亮斑外接框，也不会修改硬件传感器 ROI。校正结果通过映射取出目标区域，处理旋转、镜像和尺度后用于回环比较。

标定通过后点击应用映射与目标 ROI，后续回环和模型标定才会使用它。几何标定不负责机械移动器件，也不等于 LUT/像差标定。定位点来自传播模型；误差小不证明绝对物理尺度准确，精确测量还应使用独立尺寸参考核验。

改变 SLM、距离、目标尺寸、相机分辨率、传感器 ROI 或显示方向后，旧结果可能失效；程序会核验配置。旧的 DMD + 双 SLM 自动对准入口与此处的单 SLM 几何标定相互独立。

7. 容易混淆的按钮

按钮实际作用
控制点匹配有效区将当前所选 SLM 的控制点宽、高设为其有效宽、高；双层模式同时设置两片。只填写训练参数，不加载硬件。之后可手动降低控制点；修改有效区不会覆盖手动值，需要时再次点击。
底部「开始」执行顶部「操作」选定的离线生成、相机回环或传播模型标定。不会自动先做几何标定。
开始几何标定运行单 SLM 的定位与相机映射测量，不要求输入目标图；结束恢复原显示，不自动应用映射。
载入 / 保存参数读写子窗口的配置。载入不启动任务，也不会自动加载相位到硬件。载入后需重新核对相机映射确认。
载入标定配置读入 geometry.json 并显示结果；仍需核验并点击「应用映射与目标 ROI」。
应用映射与目标 ROI启用通过验证的相机几何矩阵，用于后续采集区域提取；不上传相位，不移动 SLM，也不裁切传感器。
使用相机中心仅填写当前原始帧的几何中心，不代表实际光学目标就在中心，不代表几何标定完成。
载入相位结果读入 result.json 并检查对应相位文件，尚不显示到硬件。
应用生成相位把结果相位导入主界面；已连接的所选 SLM 会立即显示。与「应用映射」作用不同。
停止停止当前外部进程和取帧事务，待当前操作结束后恢复原显示。不会撤回之前已保存的文件。

8. 预览、文件及常见失败

目标 / 模拟 / 实拍：分别表示目标强度、模型预测和相机采集；模拟成功不能证明实物已验证。「最近结果」可能来自上一次任务，改参数不会自动重新训练。相机预览显示最近一次任务采集帧，不是另外启动的持续录像。

文件与环境：指定外部开发环境的 Python、worker.py 和输出目录。训练及优化在独立进程中运行；主 GUI 不导入 Torch。打包后的主程序仍需外部环境才能训练。帮助文件随程序打包，可离线查看。

  • result.json：生成相位的结果入口，和 slm1/phase.png、slm2/phase.png 等文件一起保留。
  • geometry.json：几何矩阵、ROI、验证误差和对应硬件配置。
  • model.json / model.npz：传播模型说明及学习到的参数，需配套保留。未通过留出验证的模型不能用于生成。
  • captures：相位与原始采集数据；失败时也可用于排查光路。

「映射不匹配」通常需要恢复原配置或重新标定；「目标覆盖不足」应调整光路或减小目标视野；「定位相位超过采样带宽」应核对有效口径、传播距离与目标范围；「没有足够信号 / 光斑不明确」应检查照明、曝光、偏振、零级光及灰度相位方向。

几何定位失败如何查看

结果目录 captures 下保留平相位背景与各定位点的 raw.npy、raw_preview.png。probe_XX 中另有 difference.png、difference_smoothed.png、candidate_mask.png、candidates.png 和 diagnostics.json，失败也保存。绿色为通过的定位点，橙色仅表示第一候选但未通过，红色为其他候选。新版候选按去除宽缓背景后的峰值排序，并检查紧凑程度与外围拟合；差分图单独拉伸显示，原始数值请用 raw.npy。详见 captures/README.txt。

测试目标与计算尺寸

目标来源可选择粗线十字、方框或非对称 L 与圆点，无需图像文件。目标计算宽高支持 16～4096，旧版 1024 上限是软件限制；提高数值分辨率不会改变物理视野，也不保证重建细节增加。

分阶段曝光

在成像与采集中勾选“按阶段固定曝光”。几何标定使用标定曝光，模型标定与相机回环使用重建曝光。读取按钮只填参数；应用重建预览曝光会在空闲时向相机发送参数并关闭自动曝光。任务结束恢复原曝光。可先用主界面自动曝光找到亮度，再读取并固定用于任务；任务中不要自动调曝光。几何映射允许曝光/增益变化，但已标定光度模型仍要求原采集条件。

不知道目标视野设多大

几何标定页会显示聚焦定位相位最高空间频率、0.48 周期/像素限值以及按当前比例估算的最大视野。点击“调整到可标定范围”只缩小物理目标尺寸并保留余量，实际距离不变；随后重新标定。该范围不是相机可见范围，也不等于所有全息图的最大重建范围。

几何定位的有限饱和与搜索区域

几何定位允许有限的中心饱和，使用未饱和外围拟合中心；饱和范围过大、外围不完整、拟合残差高或中心不稳定仍会拒绝。回环与模型标定的强度过曝检查保持严格。

光斑最大半高全宽：原始相机像素单位。0 为自动（帧短边的 4%，限制到 12～160 px），手动最高 512 px。它限制聚焦点宽度，不是目标大小；不要为了让大片离焦亮区通过而盲目增大。

中心稳定性限值：默认 1 px，检查不同外围拟合及重复采集的中心变化。每点重复次数：默认 2，可设 1～5；每次仍使用平均帧数，1 次跳过重复采集检查。通过后取中心均值，再用独立验证点检查映射。

读取第三页 ROI：先在第三页框选原始画面区域，返回后读取。这个预设固定框必须包含全部定位点。若选择逐点辅助，任务会另行暂停并使用当前点的临时框。不修改硬件 ROI，也不是最终目标 ROI。相机或分辨率变化后需重新读取；清除搜索区域可恢复全画面。

诊断新增 compact_signal.png、候选拒绝原因、拟合宽度/残差/饱和占比和 repeatability.json。重复采集单独保存在 probe_XX_repeat_01 等目录。绿色框表示该帧定位通过，不代表整个标定已通过。修改后请重新执行几何标定。

逐点框选辅助定位

在“几何标定与 ROI”的“定位辅助”选择“逐点手动辅助”：每个点首次采集后暂停，进入第三页并冻结本次定位采集图。框住当前光斑及完整外围，留出余量，点击“确认框选并继续”。重复采集复用当前框，下一个点重新选择。

“自动定位，失败时手动辅助”只在检测失败或重复位置不稳定时请求框选；“全自动”保留原有流程。临时框只限制当前点的搜索范围，不改变相机采集 ROI，也不是最终目标 ROI。

等待时相位保持、后台采集继续，冻结图不会被新帧覆盖；可缩放和平移。失败后可重画框重新分析，也可改“重拍曝光”再重拍。重拍会更新同曝光背景并重做该点全部重复帧，曝光沿用于后续定位点。旧图及失败诊断保留；任务结束恢复原曝光和硬件显示。

框选不能代替光斑质量检查。严重散焦、过曝、外围不完整或位置不稳定仍不会通过。第三页可以直接停止标定；退出框选后恢复先前 ROI 与冻结状态。

圆环中心、探测相位与移动验证

中心识别：“紧凑亮斑”保留原来的未饱和外围拟合。“圆环 / 径向对称中心”使用明暗环边缘估计中心，再通过 180° 中心对称性细化，可处理适度椭圆环；不是最亮像素、黑色圆心的单点或整个亮面的重心。检查方向覆盖、至少数圈明暗变化、内外圈中心差及重复采集稳定性。矩形边缘、条纹、多中心、缺环或饱和外围会导致拒绝。

圆环分析半径：单位是原始相机像素，默认 100。粗框应包含中心和数圈完整内环，避免大矩形边界；程序会限制分析范围不超出框。光斑最大半高全宽仅用于亮斑模式。建议先选择“聚焦 / 菲涅尔 + 圆环中心 + 逐点手动辅助”，保留真实传播距离。

探测相位含义
聚焦 / 菲涅尔按真实传播距离生成聚焦相位；亮斑或圆环检测均可选。观察到圆环并不证明焦面、LUT 和入射波前已经正确。
圆形相位区SLM 中心固定半径的 π 相位区，边缘平滑四个硬件像素。它不是可遮光的圆形振幅孔径，也不保证生成与 Magic 软件完全相同的画面。
轴锥固定径向线性相位，周期表示径向每 2π 的物理长度；不是焦距。建议仅使用较完整的内圈。

圆形相位区、轴锥通过叠加相位斜坡移动传播图案，不在 SLM 面上直接移动圆孔。位移按自由空间菲涅尔传播关系换算；镜头参与传播或距离不准确时不能把这套数值当作绝对尺寸。程序保留物理模型坐标含义；绝对尺度仍需独立尺寸参照。

先检查移动：默认开启，先显示中心、左右、上下五个位置，检查最小位移、两个方向是否退化以及相反移动是否一致；通过后再采集九个拟合点和五个独立验证点。任何一步失败都不会生成可应用的新标定。movement_check.json 保留检查指标。关闭选项只跳过五点预检，不跳过最终拟合和独立验证。

自动准备标定曝光

勾选“标定前自动准备曝光并锁定”，程序使用首个实际探测相位及相机返回的图像调节曝光，保持增益固定；连续两轮亮度达到目标后锁定，再重新采集同曝光背景。它采用程序的图像反馈控制，不依赖各品牌 SDK 的整幅画面自动测光。全白灰度在相位型 SLM 上仍是平相位，不能代表圆环或聚焦图案的峰值，因此不以全白画面作为最终曝光依据。

“曝光亮度目标 / 满量程”默认 0.65，指所选区域平滑峰值约为白电平的 65%，并不是定位阈值。未提供搜索框时使用全幅图；圆环模式可在第三页先粗框首个图案。后续各点仍检查定位质量，不能保证首点曝光适合所有位置。准备过程及原始图保存在 exposure_preparation.json 和 captures/exposure_XX_XX。

此功能需要 SDK 返回曝光范围与实际曝光。达到最短/最长允许曝光仍不合适或多轮不稳定时停止，并保留诊断；此时再检查照明或改用手动。未勾选时保留现有手动/分阶段曝光。准备完成后固定曝光，不在回环与模型训练中自动调整；任务结束恢复原曝光。曝光时间不是检测阈值，背景噪声、圆环对称性与亮斑质量仍独立判断。

主界面 SLM 测试图案

第二页两片 SLM 的“测试图案”菜单提供“聚焦 / 菲涅尔”“圆形相位区”“轴锥”。它们与几何标定共用相位生成公式，使用本窗口当前填写或载入的参数；无需先保存参数，也无需外部 Python 或 Torch。

点击 SLM1 或 SLM2 的菜单时，分别读取该片的有效宽高、硬件像素间距和到目标平面的距离；波长、灰度相位反向、圆形相位区半径和轴锥周期读取共用设置。测试点为目标中心 (0, 0)，有效图像按原生像素居中显示，测试输出使用零旋转、零偏移及不翻转。“聚焦 / 菲涅尔”的相位由波长和距离等自动计算。

“菲涅尔（手动周期）…”用于手动观察环纹。周期参数 P 的单位为原生 SLM 像素，定义为中心至首个 2π 相位环的半径，采用二次相位 −2πr²/P²；P 越大，环纹越疏，各圈间隔并不相等。此定义不保证与 Magic 软件的“周期”数值相同。它读取当前全息有效宽高及灰度方向，不改变几何标定距离或自动相位生成方式。每片 SLM 在本次运行中分别记住最后成功显示的 P；过小而超出像素采样带宽的数值会被拒绝。

“全息参数设置…”打开本窗口。修改参数后需再次点击对应测试图案才会更新输出；已有测试画面和失败恢复均使用原来生成的图像。原输入序列保留，可点击“恢复当前输入图像”返回，测试按钮不触发自动采集。
