1. 先做什么

  • 全息生成（离线）：选择目标图、SLM、物理尺寸和传播参数，配置外部 Python 环境后点击底部「开始」。无需连接设备；完成后得到相位文件和模拟重建，尚不能代表实物效果。
  • 相机回环优化：先连接所选 SLM 与相机，固定照明和曝光，完成相机坐标映射。程序交替加载相位、采集新帧、优化，再进行最终实拍验证。
  • 传播模型标定：先完成几何映射，再采集多组灰度相位和实拍数据，拟合有效光源振幅、相位响应及像差。通过留出样本验证后，才可载入模型文件用于生成。

单 SLM 的推荐顺序：机械粗调 → 连接所选 SLM 和相机 → 设置目标视野与采集参数 →「开始几何标定」→ 检查验证结果 →「应用映射与目标 ROI」→ 相机回环或传播模型标定。

单层不要求另一片 SLM 或 DMD 连接。任务期间，已连接但未参与的另一片 SLM 会显示全黑；结束或停止后恢复原显示。照明应保持固定；当前传播模型以首片 SLM 有效区内的参考照明为基础。

2. 尺寸、像素与倍率

像素数本身没有固定的物理长度。例如同样 640 个像素，像素间距不同，代表的毫米数也不同。

参考来源如何填写
所选 SLM 有效区域使用「光路与训练」中的有效宽高和该 SLM 的像素间距。双层模式以 SLM1 为参考。
DMD 输入区域填写计划使用的 DMD 输入宽高及 DMD 像素间距。此处不要求连接 DMD，也不自动改动硬件。
自定义像素尺寸填写自定义参考宽、高（px），以及旁边的「参考像素间距」（μm）。程序自动换算物理尺寸，不需要手算。

按参考尺寸 × 倍率：目标宽高 = 参考像素宽高 × 参考像素间距 × 重建倍率。640 × 640 px、5.4 μm、倍率 1，得到 3456 × 3456 μm，即 3.456 × 3.456 mm；换为 500 × 500 px，得到 2.7 × 2.7 mm。

手动输入目标宽高：直接指定目标平面的物理尺寸，不跟随参考尺寸和倍率。页面下方始终显示换算结果。

1:1表示目标物理尺寸与所选参考区域相同，不保证一个输入像素对应一个相机像素。改变自定义尺寸不改变导出的 SLM 相位分辨率；导出尺寸由 SLM 有效宽高决定。

重建倍率与中继成像倍率不同：前者决定希望重建多大的目标；后者描述目标经成像透镜后，在相机传感器上的大小。二者不要混填。

3. 图像适配

「输入图像 / px」只显示原图尺寸。程序在内存中适配目标，不修改原文件。

  • 等比例适应 · 留边：完整保留图像，空余区域填黑，内容比例不变。
  • 等比例填满 · 裁剪：填满目标区域，超出的部分居中裁去，内容比例不变。
  • 拉伸填满：使用整张图填满目标区域；原图与目标比例不同时，内容会变形。

适配依据目标的物理宽高比，而非只看计算数组是否为方形。左侧预览可切换输入原图、当前适配后目标和最近一次训练目标。

4. ASM、控制点与传播距离

  • SLM 有效宽高：实际优化和导出的相位图像素数。有效区不等于整个硬件面板。
  • ASM 网格宽、高：数值传播计算数组的横、纵点数；宽 × 采样间距、高 × 采样间距分别决定两个方向的计算视野。开始任务时分别补足不足的方向，保留已足够的手动值。它包含有效区及外围传播区域，不能简单当作硬件分辨率。
  • ASM 数值采样：计算平面中相邻采样点的物理间距。当前模型共用物理网格，要求不粗于所用 SLM 的像素间距。视野不足时会增大网格，已有较大值会保留；内部还使用零填充。
  • SLM1 / SLM2 控制点宽、高：每片 SLM 有独立的矩形控制点数组。宽高均等于该片有效宽高时，逐像素优化，例如 1920×1080；设为 960×540 时则插值到 1920×1080。减小控制点通常按相同宽高比缩小，增加控制点不会扩大硬件区域。这些参数用于全息生成与相机回环，传播模型标定仍使用其多尺度探测图案。
  • 目标计算宽、高：表示目标与重建强度的横、纵采样点数，不是相机 ROI 宽高，也不决定物理视野。“匹配目标比例”保留计算宽度，按最终目标物理高度 ÷ 宽度计算高度并取整；仅点击时调整。例如 4320×2430 μm 的视野，计算宽度 640 对应高度 360，采样为 6.75×6.75 μm。超出范围时提示调整计算宽度。
  • 传播距离：单层填写所选 SLM 到目标平面的距离；双层还需 SLM1 到 SLM2 的距离。直接采集时目标平面是传感器面，中继采集时是被成像的重建平面。

增大计算网格不意味着光学放大；它增加计算覆盖范围及内存需求。更大的网格或更多控制点也不自动保证更好的实物重建。

5. 相机成像与采集

像元尺寸：方形像元的 X、Y 相同，因此只提供一个输入，手动修改时同时设置两个方向。IUC26000KMA 预设为 3.76 μm；「当前连接相机」优先读取 SDK。未读取到值时保留手动设置，不把未知值自动当作 4 μm。若 SDK 或旧参数中的 X、Y 不同，会保留实际值并显示提示。

采样合并 X / Y（Binning）：与原生像元尺寸不同，两个方向仍可分别核对。名义目标采样 = 像元尺寸 × 总 Binning ÷ 中继成像倍率 |M|。这些是映射参数，不会向 SDK 下发分辨率或 Binning 设置。

  • 直接采集：SLM → 相机，名义倍率为 1。
  • 中继成像：重建平面 → 成像透镜 → 相机，填写倍率绝对值。倒像、旋转和镜像由几何映射处理。
  • 透镜参与全息传播：当前模型尚不支持，不能用成像倍率代替该传播模型。

倍率来源：选择「使用已验证的标定结果」本身不会完成标定；必须先载入并应用有效的几何结果。选择手动初值会退出当前实测矩阵，需要重新确认手动映射。

暗电平、饱和电平：用于解释原始强度，不能随意当作显示亮度调节。8 位通常为 255；16 位容器不一定具有 65535 的有效饱和值。过曝应先降低曝光。

切图后等待、丢弃帧、平均帧：分别控制稳定等待、跳过新帧和平均数量。增加这些值有助于取到稳定图像，但会增加每次测量时间，不会提高相机本身帧率。

6. 几何标定与 ROI

开始几何标定是独立入口，当前支持单 SLM1 或单 SLM2。它生成聚焦定位相位，采集平相位背景、9 个拟合点和 5 个独立验证点。非对称模式也逐点显示，不是同时显示所有点。

  • 相似映射：平移、旋转、镜像及等比例尺度。
  • 仿射：额外允许横纵尺度差异与剪切。
  • 透视：描述平面投影，不包含镜头径向畸变。

允许验证误差的单位为相机原始像素。光斑不足、过曝、多个峰、边界截断、误差超限或目标覆盖不全时，不允许应用。

红色目标 ROI是指定物理矩形在相机原始画面中的投影，可能为旋转四边形。它不是亮斑外接框，也不会修改硬件传感器 ROI。校正结果通过映射取出目标区域，处理旋转、镜像和尺度后用于回环比较。

标定通过后点击应用映射与目标 ROI，后续回环和模型标定才会使用它。几何标定不负责机械移动器件，也不等于 LUT/像差标定。定位点来自传播模型；误差小不证明绝对物理尺度准确，精确测量还应使用独立尺寸参考核验。

改变 SLM、距离、目标尺寸、相机分辨率、传感器 ROI 或显示方向后，旧结果可能失效；程序会核验配置。旧的 DMD + 双 SLM 自动对准入口与此处的单 SLM 几何标定相互独立。

7. 容易混淆的按钮

按钮实际作用
控制点匹配有效区将当前所选 SLM 的控制点宽、高设为其有效宽、高；双层模式同时设置两片。只填写训练参数，不加载硬件。之后可手动降低控制点；修改有效区不会覆盖手动值，需要时再次点击。
底部「开始」执行顶部「操作」选定的离线生成、相机回环或传播模型标定。不会自动先做几何标定。
开始几何标定运行单 SLM 的定位与相机映射测量，不要求输入目标图；结束恢复原显示，不自动应用映射。
载入 / 保存参数读写子窗口的配置。载入不启动任务，也不会自动加载相位到硬件。载入后需重新核对相机映射确认。
载入标定配置读入 geometry.json 并显示结果；仍需核验并点击「应用映射与目标 ROI」。
应用映射与目标 ROI启用通过验证的相机几何矩阵，用于后续采集区域提取；不上传相位，不移动 SLM，也不裁切传感器。
使用相机中心仅填写当前原始帧的几何中心，不代表实际光学目标就在中心，不代表几何标定完成。
载入相位结果读入 result.json 并检查对应相位文件，尚不显示到硬件。
应用生成相位把结果相位导入主界面；已连接的所选 SLM 会立即显示。与「应用映射」作用不同。
停止停止当前外部进程和取帧事务，待当前操作结束后恢复原显示。不会撤回之前已保存的文件。

8. 预览、文件及常见失败

目标 / 模拟 / 实拍：分别表示目标强度、模型预测和相机采集；模拟成功不能证明实物已验证。「最近结果」可能来自上一次任务，改参数不会自动重新训练。相机预览显示最近一次任务采集帧，不是另外启动的持续录像。

文件与环境：指定外部开发环境的 Python、worker.py 和输出目录。训练及优化在独立进程中运行；主 GUI 不导入 Torch。打包后的主程序仍需外部环境才能训练。帮助文件随程序打包，可离线查看。

  • result.json：生成相位的结果入口，和 slm1/phase.png、slm2/phase.png 等文件一起保留。
  • geometry.json：几何矩阵、ROI、验证误差和对应硬件配置。
  • model.json / model.npz：传播模型说明及学习到的参数，需配套保留。未通过留出验证的模型不能用于生成。
  • captures：相位与原始采集数据；失败时也可用于排查光路。

「映射不匹配」通常需要恢复原配置或重新标定；「目标覆盖不足」应调整光路或减小目标视野；「定位相位超过采样带宽」应核对有效口径、传播距离与目标范围；「没有足够信号 / 光斑不明确」应检查照明、曝光、偏振、零级光及灰度相位方向。
